# 결과 페이지 스토리보드

대상: 비개발자, 디자이너, PO, CTO. 한 번 훑어보는 데 4분 안팎, 장면마다 핵심 문장 하나.
대표 예시 하나를 끝까지 들고 간다: SAR-02 "하 이거 들으면 잠 참 잘 오겠다" (새벽 1시, 수면 음악을 부탁했는데 헤비메탈이 나오는 중).

## 장면

| 장면 | 핵심 문장 | 화면 | 움직임 |
|---|---|---|---|
| 1. 문제 | 빠른 음성 비서는 말을 글자 그대로 받아들인다 | 대화 무대: 사람과 비서 아바타, 말풍선, 생각 말풍선, 기록 카드 | 같은 대화를 두 번: 글자 그대로 답하는 비서(빨간 테두리) → 상황 카드와 생각 말풍선으로 말뜻을 읽는 경우(초록 테두리) |
| 2. 목표 | 정확한 모델은 느리다. 빠르면서 정확한 칸을 노린다 | 지연(가로) 대 정확도(세로) 지도, 기본 모델 6개 | 점이 하나씩 떨어지고, 왼쪽 위 '목표 칸'이 서서히 밝아진다 |
| 3. 언제 일하나 | 같은 아이디어도 언제 계산하느냐에 따라 속도가 갈린다 | 한 번의 대화 턴 시간축: 말하기 전 / 말하는 중 / 말한 뒤 답 전 / 답하는 중 | 방법 칩이 제자리로 날아가고, '답 전'에 놓인 칩만큼 첫 소리 표시가 오른쪽으로 밀린다 |
| 4. 시도한 방법 | 6개 묶음, 18가지를 시험했다 | 왼쪽 방법 목록 + 오른쪽 대화 무대 | 방법을 누르면 그 방법이 하는 일을 무대로 보여 준다: 생각 말풍선(해석·점검표·짐작), 도우미(상위 모델·분석 에이전트·게이트), 기록 카드, 기다림 시계, 온도 다이얼. 비서의 말은 실제 응답 |
| 5. 결과 | 방법마다 점이 어디로 움직였나 | 장(1~3차 / 후보 선별 / 싼 추정 / 여행 개인화 / 온도)별 지연·정확도 지도 | 기준점에서 결과 위치로 점이 이동하고, 신뢰구간 막대가 뒤따라 나타난다 |
| 6. 문제점 | 좋아 보였던 방법도 대가가 있었다 | 방법별 문제 카드(숫자 하나 + 한 줄) | 카드가 시차를 두고 올라온다. 설명 글은 두 줄까지만 보이고 마우스를 올리면 펼쳐진다 |
| 7. 가장 나은 방법 | 말하기 전에 상황을 해석해 두고, 빠른 모델이 바로 답한다 | 우승 방법 강조 + 대화 무대로 전/후 예시 2개 | 지도에서 우승 점만 남고 나머지는 흐려진다. 무대에서 짐작 없이 답한 경우 → 상위 모델이 미리 만든 짐작 카드가 날아온 뒤 답한 경우 |
| 8. 다음 | 남은 질문과 방법을 더하는 방법 | 남은 질문 목록, 데이터 파일 구조 | 정적 |

## 속도

- 문장 노출: 한 글자당 약 0.12초(초당 8음절) + 정착 1.5초. 텍스트를 다 읽기 전에 다음 움직임이 시작되지 않게 한다.
- 등장 움직임 700ms, 시차 120ms, 점 이동 1,200ms(눈으로 따라갈 수 있게), 감속 곡선(easeOutCubic).
- 장면은 윗부분이 화면 위쪽 60% 안에 들어오면 시작한다(화면보다 긴 장면도 시작되도록). 장면마다 '다시 보기'가 있고, 오른쪽 아래 속도 조절(0.75배 / 1배 / 1.25배).
- 움직임 줄이기 설정(prefers-reduced-motion)이면 최종 상태를 바로 보여 준다.

## 차트 장면 시안

결과 장면(5)은 형태 판단이 어려워 시안 3개를 둔다. 본 페이지는 A 를 쓴다.

- A. 지도: 지연·정확도 평면에서 점이 이동 (`index.html`)
- B. 전후 막대: 방법마다 정확도 변화 막대와 지연 변화 막대를 나란히 키움 (`drafts/chart-b.html`)
- C. 입체: 지연·정확도·비용 3축 공간에서 기둥이 솟고 시점이 천천히 돈다, three.js (`drafts/chart-c.html`)

## 방법 더하기

1. `vib/site_data.py` 의 `METRICS` 에 결과 파일 경로를 더하고 `python -m vib.site_data` 로 `site/data/metrics.json` 을 다시 만든다.
2. `site/data/methods.json` 에 카드(묶음, 계산 시점, 역할, 예시 프롬프트·출력, 문제점, 지표 키)를, `site/data/stages.json` 에 무대 대본(say, think, cards, helper, clock, dial 단계)을 더한다. 비서의 말과 짐작은 실제 결과에서 가져온다.
3. 결과 장면에 보이려면 `site/data/chapters.json` 의 해당 장에 점을 더한다. 새 장도 같은 형식으로 더한다.
